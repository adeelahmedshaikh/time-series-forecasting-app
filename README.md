# 📈 Auto Time-Series Forecasting & Decision App

A web application that automatically forecasts time-series data, selects the best model, and provides actionable insights.

## 🚀 Features

- Upload any CSV file
- Automatic column detection (date & target)
- Multiple models:
  - Naive Baseline
  - Moving Average
  - Random Forest
  - XGBoost
- Automatic best model selection (based on MAE)
- Forecast for 7, 14, or 30 days
- Trend analysis & risk detection
- Domain-aware recommendations
- Download forecast results as CSV
- Fully deployed web app

## 🧠 How it works

1. Upload your dataset  
2. System detects columns automatically  
3. Models are trained and evaluated  
4. Best model is selected  
5. Forecast + insights are generated
